# Cisco Packet Tracer – Networking Practice Labs

## Overview
A collection of hands-on networking labs completed using Cisco Packet Tracer to develop practical knowledge of networking fundamentals, device configuration, routing, network services and troubleshooting.

## Labs Included

| Lab | Topic |
|---|---|
| 01 | LAN Switching and ARP |
| 02 | DHCP Configuration |
| 03 | VLAN Configuration |
| 04 | Static Routing |
| 05 | Network Address Translation (NAT) |
| 06 | ACL Traffic Filtering |
| 07 | Extended ACL Configuration |
| 08 | RIPv2 Dynamic Routing |
| 09 | Wireless LAN Configuration |
| 10 | Network Troubleshooting |

## Skills Practised
- LAN fundamentals and Ethernet switching
- IPv4 addressing and subnetting
- VLANs and trunking
- DHCP and NAT
- Static and dynamic routing
- Access Control Lists (ACLs)
- Wireless networking
- Network troubleshooting and connectivity testing

## Tools
Cisco Packet Tracer

## File Format
All lab files are provided in `.pkt` format and can be opened using Cisco Packet Tracer.
